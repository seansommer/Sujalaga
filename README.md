# SUJALAGA!

Fill the fleet. Rule the galaxy.

A SUJA arcade flight game with four 3D juice sectors, diving bottle formations, mega-bottle bosses, upgrades, and a charged Juice Surge. Arcade, Endless, and Practice modes support touch, on-screen steering, and keyboard controls.

[Play in SUJA Game Center](https://seansommer.github.io/sujagamecenter/sujalaga.html)

Original artwork, procedural 3D models, and an original synthesized soundtrack. The Game Center supplies the shared player account and competitive standings.

Build: `npm ci && npm test && npm run build`.
