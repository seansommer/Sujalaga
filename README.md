# SUJALAGA!

Fill the fleet. Rule the galaxy.

A SUJA arcade flight game with four 3D juice sectors, varied diving bottle formations, distinct mega-bottle bosses, upgrades, and a charged Juice Surge. Arcade, Endless, and Practice modes support relative thumb steering in a clear area below the ship, limited forward/backward movement, and arrow-key or WASD controls.

[Play in SUJA Game Center](https://seansommer.github.io/sujagamecenter/sujalaga.html)

Original artwork and procedural 3D models accompany a CC0 arcade soundtrack with separate sector and boss music, sampled effects, and synthesized accents. See [audio credits](assets/audio/CREDITS.txt). Lasers match each juice sector, and the right-side Juice Surge meter fills upward with animated feedback when ready. The Game Center supplies the shared player account and competitive standings.

Build: `npm ci && npm test && npm run build`.
